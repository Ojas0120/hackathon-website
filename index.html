The Quantum revolution is here

QtHack04 is an interdisciplinary quantum technologies hackathon designed to push the boundaries of quantum hardware, RF technology, and applied optics. Over 48 intense hours, brilliant minds will converge to solve 15 highly specialized problem statements across 3 major tracks.

Objective

Design and implement interactive visual simulations that demonstrate the working principles of optical, electronic, RF, and quantum systems. Teams must model the physics, visualize system behavior, and extract meaningful parameters through simulations.

Track 01 — Applied Optics & Photonics

#01

Visual Interferometer Simulator

Develop a visual tool to simulate and analyze interference patterns generated by various interferometer configurations.

Simulation
#02

Fringe Visibility Analyzer

Create software to calculate and visualize fringe visibility from raw optical sensor data arrays.

Data Analysis
#03

Diffraction Pattern Visualizer

Build an interactive 3D visualizer for mapping complex diffraction patterns under varying aperture conditions.

3D Visualization
#04

Virtual Optical Microscope

Design a digital twin of an optical microscope allowing adjustment of focal length, magnification, and light source.

Digital Twin
#05

Polarization Optics Visual Lab

A virtual laboratory for students to experiment with waveplates, polarizers, and unpolarized light states.

EdTech Tool

Track 02 — Quantum Hardware Core

#06

RLC Frequency Response Simulator

Develop a robust simulator to plot Bode plots and resonant frequencies for complex RLC hardware circuits.

Circuit Design
#07

RLC Ring-Down Energy Visualizer

Visualize the exponential decay and energy loss in superconducting LC circuits over time.

Hardware Analysis
#08

Digital Adder Visual Simulator

Create a gate-level simulator mapping classical digital adder logic onto quantum reversible gate equivalents.

Logic Gates
#09

Binary Multiplier Visual Demo

Animate the step-by-step process of binary multiplication using fundamental quantum gates.

Algorithm
#10

Flip-Flop & Shift Register Animator

Design a visual state machine animator showing data flow through shift registers and flip-flops in real-time.

State Machine

Track 03 — RF Technology & Instrumentation

#11

Virtual Oscilloscope for RLC

Build a web-based oscilloscope interface processing and rendering high-frequency RLC signals with trigger functions.

Instrumentation
#12

VNA Reflection & VSWR Simulator

Simulate a Vector Network Analyzer measuring S11 parameters and Voltage Standing Wave Ratio of antennas.

RF Simulation
#13

Two-Port Network Characterization

Develop a tool to extract and plot S-parameters for standard 2-port RF microwave components.

Microwave Eng.
#14

Three-Port Network Signal Flow

Visualize signal routing, isolation, and insertion loss in circulators and power dividers using flow graphs.

Signal Routing
#15

Thermal Noise Visual Analyzer

Analyze and visualize the impact of thermal noise floor variations on quantum RF readout fidelity.

Noise Analysis
